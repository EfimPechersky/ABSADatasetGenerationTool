# ABSA DATASET GENERATION TOOL

Этот репозиторий содержит исходный код инструмента, который позволяет генерировать датасеты, обучать маловесную модель microsoft/mdeberta-v3-base на синтетических данных, а также проводить аспектно-ориентированный анализ тональности отзывов при помощи настроенной модели.

## Требования к среде развертывания

### Минимальные требования

- Операционная система: Linux, Windows (с WSL2)
- Docker Engine 20.10+
- Docker Compose 2.0+
- NVIDIA Docker Runtime (для использования GPU)

### Ресурсы

| Компонент | Минимально | Рекомендуемо |
|-----------|------------|--------------|
| CPU | 2 ядра | 4 ядра |
| RAM | 4 ГБ | 8 ГБ |
| GPU | - | NVIDIA GPU с поддержкой CUDA |
| Дисковое пространство | 22 ГБ | 25 ГБ |

**Примечание:** общий вес контейнеров может достигать до 22 ГБ при первом развертывании.

### Зависимости для GPU

Для использования GPU в контейнере backend необходимо установить:
- NVIDIA драйверы (версия 470+)
- NVIDIA Container Toolkit

Инструмент использует LLM для генерации примеров. Для уменьшения требований к среде развертывания рекомендуется использовать более мощную среду для развертывания LLM, например Google Colab.

Ссылка на блокнот Google Colab: https://colab.research.google.com/drive/13_SW3NV8PyOS0Op9fMN3HhtUZGpNeSvk?usp=sharing

## Развертывание в Docker

### Предварительные настройки

1. Убедитесь, что Docker и Docker Compose установлены
2. Подготовьте ссылку на API с развернутой LLM

### Запуск

Перейдя в корневую папку проекта, выполните команду:
```bash
$env:LLM_API_URL="https://your-llm-api-url/with-endpoint"; docker-compose up -d
```
Для Linux/macOS используйте:
```bash
LLM_API_URL="https://your-llm-api-url/with-endpoint" docker-compose up -d
```
### Создаваемые контейнеры

Будут созданы три контейнера:

| Контейнер | Назначение | Порт |
|-----------|------------|------|
| Backend | Серверная часть с ML-моделью | 8000 |
| Database | PostgreSQL | 5432 |
| Frontend | Веб-интерфейс | 3000 |

### Переменные окружения

| Переменная | Описание | Значение по умолчанию |
|------------|----------|----------------------|
| LLM_API_URL | URL API LLM (обязательная) | - |
| DB_USER | Пользователь базы данных | postgres |
| DB_PASSWORD | Пароль базы данных | mysecretpassword |
| DB_NAME | Имя базы данных | postgres |
| SECRET_KEY | Секретный ключ для JWT | your-super-secret-key-change-this |
| ALGORITHM | Алгоритм шифрования JWT | HS256 |
| ACCESS_TOKEN_EXPIRE_MINUTES | Время жизни токена (минуты) | 300 |

### Процесс запуска

1. При первом запуске контейнеров будет произведена загрузка необходимых моделей
2. Интерфейс станет доступным в браузере по адресу: http://localhost:3000
3. Когда модели будут загружены, интерфейс станет активным, и вы сможете воспользоваться инструментом

### Остановка контейнеров
```bash
docker-compose down
```
Для полной очистки данных (включая том базы данных):
```bash
docker-compose down -v
```
